## 한 일
- **엑셀에서 복사해 붙여넣기** — 엑셀 파일을 읽는 곳은 「데이터 관리 → Audit 양식」 하나였다. 종류마다 붙여넣기 칸을 두고, 붙여넣은 글자를 `QA.parsePaste` 로 표(aoa)로 바꿔 **파일과 같은 `QA.parseFormBook`** 에 넘긴다. 머리글 찾기 · 공정 물려받기 · 합계 줄 · 빈 행 3개 · 천 단위 쉼표 · 열 직접 고르기가 파일과 하나다. PSO 는 Pre-PSO 기본 · 상세 · PSO 기본을 부분마다 골라 쌓는다(`QA.pasteBook`).
- 공정점검 가로 표에도 붙여넣기 — `QA.parseInspectRows`(한글 머리글로 열 찾기, 없으면 화면 열 순서, 앞 번호 열 건너뜀). 날짜 `QA.normDate`(2026-11-04 · 2026.11.4 · 2026. 11. 4. · 2026년 11월 4일 · 26.11.04 · 20261104 · 시각 · 요일 · 엑셀 일련번호 · 연도 없는 11/4 는 점검 연도). 못 읽은 날짜 · 상태는 비우거나 「요청」으로 두고 경고 — 지어내지 않는다.
- CSV · TSV · TXT 파일도 고를 수 있다. 인코딩은 BOM → UTF-8 → CP949(한국어 윈도 엑셀 CSV 기본) 순(`QA.decodeText`).
- 결과 꺼내기 — 시트 5장마다 「표 복사」(엑셀 A1 에 붙이는 탭 글자, `QA.toTSV`) · CSV(BOM, `QA.toCSV`), 백업 JSON 을 붙여 넣어 복원.
- **오프라인 사용 파일** — `tools/make-offline.js` 가 index.html 에 css · SheetJS · audit.js · app.js 를 넣은 HTML 하나(`offline/qa-2611-14-offline.html`, 799KB)를 만든다. canonical · og 주소 · 사용법/기획서 링크는 뺀다. 데이터 관리에 「오프라인 사용 파일 받기」, 오프라인 파일에서는 그 자리에 오프라인 안내. 글꼴은 원래 @font-face 없이 PC 글꼴을 쓰고 있었다.
- `tools/check-offline.js` — 최신인지(다시 만든 것과 같은지), 마크업 src/href · meta · CSS url( · @import · @font-face · fetch(선택 AI 두 주소만) · XHR · Worker 등 바깥 자원/네트워크 호출이 없는지. test.yml 에 넣었다.
- 저장은 그대로 브라우저 IndexedDB(선택 상태만 localStorage). 오프라인 파일과 온라인 주소는 저장소가 따로라 백업 JSON 으로 옮긴다고 화면 · 사용법에 적었다.
- 주소 변경 — https://build-2611-14.jobability.co.kr/ (index.html canonical · og, README, CLAUDE.md, plan.json `url`).
